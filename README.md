# ConsultorioFacil

Sistema de gestão para consultórios médicos.


Objetivo

• Reduzir o tempo gasto pelo profissional de saúde com tarefas administrativas.

Princípios

• O usuário é a estrela do espetáculo.

• Nunca exigir treinamento.

• Automatizar tudo o que puder ser automatizado.

• Evitar digitação desnecessária.

• O sistema deve pensar antes do usuário precisar pensar.

• Cada clique deve ter um propósito.
